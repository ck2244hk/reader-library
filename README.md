# Reader Library

A personal library for organizing learning sessions generated by the **web-reader-learn** skill.

## Setup

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages → Source** and set it to **GitHub Actions**
3. Push to `main` — the workflow in `.github/workflows/deploy.yml` handles the rest

Your library will be live at: `https://<your-username>.github.io/<repo-name>/`

---

## Adding a New Session

When the skill generates a new learning session HTML file:

**1. Drop the HTML file into `/public/sessions/`**

```
public/
  sessions/
    vulkan-overview-learning.html   ← existing
    my-new-session.html             ← new one here
```

**2. Add an entry to `/public/sessions.json`**

```json
{
  "id": "my-new-session",
  "title": "Page Title Here",
  "url": "https://original-url.com/page",
  "date": "2026-06-04",
  "tags": ["topic", "another-topic"],
  "questionCount": 7,
  "file": "sessions/my-new-session.html",
  "excerpt": "One sentence describing what this session covers."
}
```

**3. Commit and push** — GitHub Actions redeploys automatically.
